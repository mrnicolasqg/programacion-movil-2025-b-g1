 API de Usuarios – Taller Unidad 2

Este proyecto implementa una **API REST básica** para la gestión de usuarios, desarrollada con **Node.js y Express**, como parte del **Taller Unidad 2 – Tecnologías y Frameworks para el Desarrollo Móvil**.

El objetivo es comprender cómo funcionan los endpoints de una API (GET, POST, PUT, DELETE), el almacenamiento de datos en formato JSON y el uso de buenas prácticas en el desarrollo backend.
